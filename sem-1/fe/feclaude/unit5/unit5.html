1. What is an amplifier?

In short: an amplifier makes a weak signal stronger without changing its shape. The extra energy comes from the DC power supply.
  • Gain = output ÷ input. It has no unit.
  • Gain can be large (10 000), so we often write it in decibels (dB), a log scale.
  • In a multistage amplifier, gains multiply (A = A1·A2·…) but dB gains simply add.
Voltage gain Av = VoVi  ·  Current gain Ai = IoIi  ·  Power gain Ap = PoPi = Av × Ai
In dB:   Av(dB) = 20 log10 Av  ·  Ap(dB) = 10 log10 Ap  ·  back from dB: Av = 10dB/20

Remember: every ×10 in voltage gain = +20 dB. So 80 dB → 104, 40 dB → 100.

  2. Medium A 2-stage amplifier has gains 20 and 50. Total gain in dB? Ans: 20 × 50 = 1000 → 60 dB (or 26 dB + 34 dB = 60 dB).
  3. Hard Why can an amplifier's output power exceed its input power? Ans: the transistor only controls; the extra power comes from the DC supply VCC.

3. Feedback: the basic idea

In short: feedback means taking part of the output and sending it back to the input, where it is mixed with the input signal.
  • Feedback: a process in which part of the output (voltage or current) is returned to the input.
  • Feedback amplifier: an amplifier that works on the principle of feedback.
  • It has two parts: the basic amplifier (gain A) and the feedback network (fraction β, usually just resistors).
  • Four blocks to name: mixer (adds/subtracts at input) → amplifier A → sampler (takes a sample of output) → feedback network β.
Feedback factor   β = VfVo   (also called the reverse transmission factor or feedback ratio; β = 0.09 means 9% of the output is fed back)
  • Open-loop gain (A): gain without feedback, the loop is "opened".
  • Closed-loop gain (Af): gain with feedback, the loop is "closed". For negative feedback Af < A.
  • Loop gain: Aβ, the gain going once around the loop.
Draw: Fig. 4 in every feedback answer. Label mixer, A, sampler, β, Vs, Vi, Vf, Vo.
PRACTICE
  1. Easy What is the difference between open-loop and closed-loop gain? Ans: open-loop = without feedback (A); closed-loop = with feedback (Af).
  2. Easy What does β = 0.01 mean? Ans: 1% of the output voltage is fed back to the input.
  3. Medium Name the four blocks of a feedback amplifier. Ans: mixer, basic amplifier (A), sampler, feedback network (β).

4. Positive vs negative feedback

In short: if the fed-back signal is in phase with the input it adds (positive feedback); if it is 180° out of phase it subtracts (negative feedback).

Why 180°? A CE amplifier itself gives 180° phase shift. For positive feedback the feedback network adds another 180° (total 360° = in phase). For negative feedback the network adds 0° (total 180° = opposite).

Remember: if Aβ = 1 with positive feedback, Af = A/0 → ∞: the circuit gives output with no input. That is an oscillator (Barkhausen criterion: |Aβ| = 1, total phase 360°).
PRACTICE
  1. Easy Which feedback is used in oscillators? Ans: positive feedback.
  2. Medium Why is negative feedback used in amplifiers even though it reduces gain? Ans: it gives stable gain, less distortion and noise, more bandwidth and better impedances.
  3. Hard State the Barkhausen criterion. Ans: loop gain |Aβ| = 1 and total phase shift around the loop = 0° or 360°.

5. Gain with negative feedback (derivation)

In short: negative feedback divides the gain by (1 + Aβ). [A5-Q2]

Use Fig. 4. Let Vs = input signal, Vi = input reaching the amplifier, Vo = output, Vf = feedback voltage.

  1. Gain of the basic amplifier:   A = VoVi   ⇒   Vo = A·Vi  …(1)
  2. Feedback voltage:   Vf = β·Vo  …(2)
  3. Negative feedback subtracts at the mixer:   Vi = Vs − Vf = Vs − βVo  …(3)
  4. Put (3) in (1):   Vo = A(Vs − βVo) = AVs − AβVo
  5. Collect Vo terms:   Vo + AβVo = AVs  ⇒  Vo(1 + Aβ) = AVs
  6. Closed-loop gain:
Af = VoVs = A1 + Aβ     and if Aβ ≫ 1:   Af ≈ 1β
  • (1 + Aβ) is called the desensitivity factor (or amount of feedback). Since it is > 1, Af < A.
  • Amount of feedback in dB = 20 log10(Af/A) = −20 log10(1 + Aβ) (negative number → gain reduction).
  • When Aβ ≫ 1, the gain depends only on β (a few resistors), not on the transistor. This is the main reason negative feedback is used.

Teacher's example (Fig. 13.3 idea)

An amplifier gives 10 V output for 1 mV input → A = 10 V / 1 mV = 10 000. The feedback circuit returns mv = β = 100 mV / 10 V = 0.01 of the output. Because the feedback is negative, the source must now supply 101 mV for the amplifier input to still be 1 mV:

Af = 10 V101 mV ≈ 99 ≈ 100    check: A1 + Aβ = 10 0001 + 100 = 99 ≈ 1/β = 100 ✓
PRACTICE
  1. Easy Write Af for negative feedback. Ans: Af = A/(1 + Aβ).
  2. Medium If Aβ ≫ 1, what does Af depend on? Ans: only on β (Af ≈ 1/β).

6. Characteristics of negative feedback

In short: we "pay" with gain (÷ by 1 + Aβ) and in return almost everything else improves by the same factor (1 + Aβ). [A5-Q3]

1. Gain stability (desensitivity)

The gain of a transistor changes with temperature, ageing, supply voltage and replacement. With negative feedback Af ≈ 1/β, which depends only on stable resistors.

dAfAf = 11 + Aβ · dAA    e.g. a 10% change in A with (1 + Aβ) = 100 gives only a 0.1% change in Af.

2. Reduces non-linear distortion

Large signals cause distortion because the gain changes along the cycle. Feedback brings back the distorted part in opposite phase and cancels most of it.

Df = D1 + Aβ   (D = distortion without feedback, Df = with feedback)

3. Increases bandwidth (improves frequency response)

The feedback network is resistive, so Af ≈ 1/β does not depend on frequency. Gain stays flat over a wider range.

fHf = fH(1 + Aβ)
fLf = fL1 + Aβ
Gain × Bandwidth = constant
A × BW = Af × BWf

Feedback trades gain for bandwidth: the gain falls by (1 + Aβ) and the bandwidth rises by about the same factor.

4. Increases circuit stability

If the output tries to rise (e.g. temperature increase), more voltage is fed back, which reduces Vi and pulls the output back down. The opposite happens if the output falls. So the output is self-correcting.

5. Reduces noise

Noise produced inside the amplifier is reduced by (1 + Aβ): Nf = N/(1 + Aβ).

6. Changes input and output impedance (useful for impedance matching)

Voltage-series feedback:   Zif = Zin(1 + Aβ) ↑   ·   Zof = Zout1 + Aβ ↓

High input impedance means it does not load the source; low output impedance means it can drive a load. This is ideal for a voltage amplifier. (Other types change Z differently, see Section 7.)

Disadvantages

  • Gain is reduced, so more stages are needed.
  • If phase shifts at high frequency turn the feedback positive, the circuit may oscillate.

7. Four types of feedback amplifiers

In short: the name tells you two things: what is sampled at the output (voltage or current) and how it is mixed at the input (series or shunt). [A5-Q4]
  • Voltage sampling = feedback network connected in shunt (parallel) with the output. Current sampling = connected in series with the load.
  • Series mixing = feedback voltage added in series with the source. Shunt mixing = feedback current added in parallel at the input.
  • Rule: series raises the impedance at that port, shunt lowers it.

8. Solved numericals

In short: always convert dB to plain numbers first, use Af = A/(1 + Aβ), then convert back to dB if asked.
dB → number: A = 10dB/20  ·  number → dB: 20 log10A  ·  Af = A/(1 + Aβ)  ·  β = (A/Af) − 1A  ·  A = Af1 − Afβ

Problem 1 (teacher's slide)

An internal amplifier has a voltage gain of 60 dB and uses 0.1 of the output voltage as feedback. Find the gain of the negative feedback amplifier in dB.

  1. 60 dB → A = 1060/20 = 103 = 1000; β = 0.1.
  2. Af = 1000 / (1 + 1000 × 0.1) = 1000 / 101 = 9.9.
  3. In dB: 20 log 9.9 = 19.9 dB.

Problem 2 — finding β

An amplifier without feedback has gain 500. With negative feedback the gain falls to 50. Find β.

  1. 1 + Aβ = A / Af = 500 / 50 = 10.
  2. Aβ = 9  ⇒  β = 9 / 500 = 0.018 (1.8% fed back).

Problem 3 — finding A

Af = 25 and β = 0.03. Find the open-loop gain A.

  1. 25 = A / (1 + 0.03A)  ⇒  25 + 0.75A = A.
  2. 0.25A = 25  ⇒  A = 100.

  2. Easy [A5-Q6] A = 100, β = 0.09. Find Af. Ans: 100 / (1 + 9) = 10.
  3. Medium [A5-Q7] A = 40 dB, β = 0.09. Closed-loop gain in dB? Ans: A = 100 → Af = 100/10 = 10 → 20 dB.
  4. Easy [A5-Q8] A = 500, Af = 50. Find β. Ans: β = 0.018 (Problem 2).

9. Amplifiers in communication systems

In short: radio signals are extremely weak when they reach the antenna, and must be powerful when they leave it. Amplifiers do both jobs.
  • Low-noise amplifier (LNA): first stage after the antenna; boosts microvolt signals while adding very little noise (mobile phones, Wi-Fi, GPS, satellite dishes).
  • IF amplifier: a tuned amplifier giving most of the receiver's gain. Automatic Gain Control (AGC) is a negative-feedback loop that keeps the output level constant whether the station is near or far.
  • Audio power amplifier: drives the speaker (Class AB push-pull).
  • RF power amplifier: in the transmitter / mobile tower; Class C for FM (high efficiency), linear Class AB for 4G/5G signals.
  • Repeaters in long cables and satellites re-amplify the weakened signal.
PRACTICE
  1. Easy What is the first amplifier in a receiver called? Ans: RF amplifier / low-noise amplifier (LNA).
  2. Medium Which feedback is used in AGC and why? Ans: negative feedback, so that a strong signal reduces the gain and the output stays constant.

10. Amplifiers in data acquisition

In short: a data acquisition (DAQ) system measures real-world quantities with sensors and sends them to a computer. Sensor signals are tiny (millivolts), so they are amplified before the ADC.
  • Instrumentation amplifier: a precise differential amplifier with very high input impedance and high CMRR; amplifies the small difference between two sensor wires and rejects common noise (ECG machines, weighing scales, strain gauges).
  • Programmable-gain amplifier (PGA): gain is changed by the computer so both small and large signals use the full ADC range.
  • Negative feedback (resistor-set gain) makes the measurement accurate and stable with temperature, exactly the gain-stability property from Section 6.
  • Examples: industrial sensors, weather stations, medical monitors, lab equipment, IoT devices.
PRACTICE
  1. Easy Why amplify a sensor signal before the ADC? Ans: sensor output is only mV; amplifying it uses the ADC's full range and improves resolution.
  2. Medium Why does an instrumentation amplifier need high input impedance? Ans: so it does not load (draw current from) the sensor and change its reading.

12. Amplifiers in cloud / data-centre hardware

In short: a data centre is thousands of servers joined by very fast links. Amplifiers carry the data between chips and racks, and feedback amplifiers keep the power supply to CPUs/GPUs rock-steady.
  • High-speed links (SerDes): data travels between chips at 50–200 Gb/s per lane. Receiver amplifiers with equalisation (e.g. CTLE) boost the high frequencies that the copper traces weaken.
  • Optical transceivers (400G / 800G modules joining server racks): laser-driver amplifiers on the transmit side and TIAs on the receive side, the same as in Section 11 but at much higher speed.
  • Voltage regulators (VRMs): a CPU or AI GPU needs ~1 V at hundreds of amperes, and the load changes in microseconds. An error amplifier compares the output voltage with a reference and corrects it: this is negative feedback giving a stable output.
  • Monitoring: current-sense and temperature-sensor amplifiers (a DAQ system inside each server) let software track power and cooling.
  • Wireless/edge links: RF amplifiers connect cell towers and edge servers to the cloud.
Link to theory: TIA = voltage-shunt feedback; regulator error amp = negative feedback for gain stability; wide bandwidth in fast links = feedback trading gain for bandwidth.
PRACTICE
  1. Medium How does negative feedback help a CPU's voltage regulator? Ans: the error amplifier senses any change in output voltage and corrects it, so the CPU gets a constant voltage even when its load changes.
  2. Hard List four places amplifiers are used in cloud infrastructure. Ans: SerDes receivers, optical transceivers (laser driver + TIA), voltage-regulator error amplifiers, sensor/current-monitoring amplifiers.
